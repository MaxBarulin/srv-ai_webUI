# Исходники презентации

`../presentation.pptx` собирается скриптом, а не правится руками — так проще
менять цифры и порядок слайдов, не разбирая XML.

```bash
cd docs/presentation-src
node build.js          # перезапишет ../presentation.pptx
```

Нужен `pptxgenjs` (`npm i pptxgenjs`). Кадры интерфейса лежат в `shots/`;
снимаются на стенде с демонстрационными данными, ширина 1960.

Структура: титул → блок I «для руководства» → блок II «для технических
специалистов» → что дальше. Блоки разделены слайдами-заставками, чтобы
показывать только нужную половину.

При смене цифр проверить:
- слайд «Производительность» — токены/с;
- слайд «Модель» — параметры запуска llama.cpp;
- слайд «База знаний» — включён ли RAG.
